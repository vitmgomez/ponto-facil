# Ponto Fácil - Controle de Frequência

Sistema web para registro de ponto eletrônico e controle de jornada diária de colaboradores.

## Sobre o Projeto

O **Ponto Fácil** permite registrar marcações de turno em tempo real, acompanhar o status do dia, calcular o total de horas trabalhadas e manter o histórico salvo no navegador.

## Funcionalidades

* **Relógio Digital:** Exibição da data e hora atual em tempo real.
* **Identificação:** Campo para nome ou matrícula do colaborador.
* **Registro de Turnos:** Marcações de `Entrada`, `Saída Almoço`, `Volta Almoço` e `Saída`.
* **Resumo Diário:** Exibição dos horários registrados no dia, status atual da jornada e cálculo do total de horas trabalhadas.
* **Persistência Local:** Armazenamento dos registros via Web Storage (`localStorage`).
* **Histórico e Exportação:** Tabela de registros (Data, Colaborador, Tipo e Horário) com opções para exportar em `.csv` ou limpar o histórico.
